Un’impronta, non un verdetto

SHA-256 identifica il contenuto di un file. Puoi confrontarlo con l’impronta fornita dall’autore. Da solo, un hash non rileva un malware.

Hai un sospetto concreto?

Non aprire il file. Aggiorna il tuo antivirus ed esegui una scansione completa con uno strumento di sistema. Non caricare documenti riservati su servizi pubblici.

COME FUNZIONA DAVVERO

Sicurezza, senza
false promesse.

Cosa controlliamo, cosa resta fuori e come andare oltre.

Cosa fa Aegis

  • Legge tutti i byte dei file scelti, fino a 128 MiB ciascuno.
  • Cerca la firma di test EICAR e alcuni indicatori euristici.
  • Calcola SHA-256 per file fino a 32 MiB.
  • Verifica il contesto della pagina e le API del browser.
  • Cerca vulnerabilità note di pacchetti tramite OSV.
  • Esporta report con evidenze e limitazioni.

Cosa richiede un altro strumento

  • Accesso completo a disco, memoria, processi e settori.
  • Rilevamento completo di virus, rootkit o spyware.
  • Analisi interna di archivi, macro e documenti cifrati.
  • Verifica delle patch e dei programmi installati.
  • Accertamento di furti di dati o danni al dispositivo.
  • Rimozione, riparazione o quarantena dei file.

Per una scansione completa del dispositivo

Il passo successivo si fa sul sistema, con strumenti autorizzati.

  1. 01

    Aggiorna sistema e protezioni

    Installa gli aggiornamenti del sistema operativo e aggiorna il database del tuo antivirus.

  2. 02

    Avvia una scansione completa

    Su Windows usa Sicurezza di Windows → Protezione da virus e minacce → Opzioni di analisi. Per altri sistemi usa uno strumento affidabile compatibile con il tuo sistema.

  3. 03

    Se sospetti un’intrusione, preserva le prove

    Evita di eseguire file sospetti. Per furti, danni o incidenti seri rivolgiti a un professionista: una pagina web non può confermarli o escluderli.
